# PQ（性能適格性確認）: CIR Usecase List（ITSM Core）

## 目的

代表的な Issue 数/プロジェクト数において、一覧/抽出が許容範囲で応答することを確認する（最小）。

## 対象

- ワークフロー（正）: `apps/itsm_core/cir_usecase_list/workflows/`
- 外部 API: GitLab API（Issue 一覧/検索）

## 指標（最低限）

- 応答時間（p95）が許容範囲内
- API 制限（rate limit）で過度に失敗しない（必要ならリトライで回復する）
- 出力が過度に肥大化しない（運用で扱える範囲）

## 実施方法（最小）

- 代表的なプロジェクト/Issue 数の条件で複数回実行し、実行時間と結果件数を記録する

## 証跡（最小）

- 実行ログ（対象条件、結果件数、時間）
