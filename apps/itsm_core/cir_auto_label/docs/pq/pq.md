# PQ（性能適格性確認）: CIR Auto Label（ITSM Core）

## 目的

起票イベントのピーク時にも、ラベル付与が遅延/取りこぼしなく処理できることを確認する（最小）。

## 対象

- ワークフロー（正）: `apps/itsm_core/cir_auto_label/workflows/`
- 外部 API: GitLab Webhook / GitLab API（ラベル付与）

## 指標（最低限）

- 取りこぼしがない（再送/重複イベントでも安全側に収束する）
- 実行時間が過度に伸びない

## 実施方法（最小）

- テスト用イベント（または OQ の代表ケース）を複数回実行し、ラベル付与結果とログを保存する

## 証跡（evidence）
- 実行ログ（対象 Issue、付与ラベル、結果）
