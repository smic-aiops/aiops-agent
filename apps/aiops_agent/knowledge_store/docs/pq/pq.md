# PQ（性能適格性確認）: Knowledge Store（AIOps Agent）

## 目的

代表的な検索/問い合わせ負荷において、許容可能な応答が得られることを確認する（最小）。

## 対象

- DB 参照/更新のワークフロー（正）: `apps/aiops_agent/knowledge_store/workflows/`
- 必要に応じて DB（RDS Postgres）とインデックス（方式は実装を正とする）

## 指標（最低限）

- 代表クエリの応答時間（p95）が許容範囲内
- タイムアウト/5xx が過度に発生しない

## 実施方法（最小）

- OQ の代表シナリオ（またはテスト webhook）を複数回実行し、結果と応答時間を記録する

## 証跡（evidence）
- 実行ログ（クエリ種別、件数、代表的な応答時間）
