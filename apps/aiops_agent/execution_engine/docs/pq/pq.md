# PQ（性能適格性確認）: Execution Engine（AIOps Agent）

## 目的

代表的なジョブ量/頻度において、キュー処理が過度に滞留しないことを確認する（最小）。

## 対象

- ジョブ投入/実行のワークフロー（正）: `apps/aiops_agent/execution_engine/workflows/`

## 指標（最低限）

- Queue 滞留時間（概算でよい）と失敗率が許容範囲内
- リトライ/再実行で回復できること

## 実施方法（最小）

- OQ の代表シナリオを複数回実行し、n8n 実行ログから待ち時間/実行時間/失敗を記録する

## 証跡（evidence）
- 実行ログ（件数、失敗の有無、代表的な実行時間）
