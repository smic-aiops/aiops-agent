# Workflow Manager ドキュメント

Workflow Manager の共通（overview）ドキュメントはこのディレクトリ（`apps/workflow_manager/workflow_catalog/docs/shared/`）に配置します。

- セットアップ全体: `docs/setup-guide.md`
- ワークフロー同期（全体）: `apps/workflow_manager/scripts/deploy_all_workflows.sh`
- ワークフロー同期（機能別）:
  - Workflow Catalog: `apps/workflow_manager/workflow_catalog/scripts/deploy_workflows.sh`
  - Service Request: `apps/workflow_manager/service_request/scripts/deploy_workflows.sh`
